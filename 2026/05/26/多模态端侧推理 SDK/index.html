八、MVP 路线图

Phase 1 — 单模态可用 (8 weeks)

周次 任务
Week 1-3 Runtime 核心 (Tensor/Metal/CPU/内存管理)
Week 4-5 LLM 推理 (Qwen2.5-1.5B INT4)
Week 6-7 iOS SDK 封装 + Demo APP
Week 8 Android SDK 封装 + Demo APP

交付： 两端能跑通文本对话，benchmark 达标

Phase 2 — 多模态串联 (6 weeks)

周次 任务
Week 9-10 Pipeline Orchestrator
Week 11-12 Vision 模块 (CLIP + YOLO)
Week 13-14 VLM 串联 (图片问答端到端)

交付： 拍照问答 Demo，Pipeline API 稳定

Phase 3 — 语音闭环 (6 weeks)

周次 任务
Week 15-16 ASR (Whisper)
Week 17-18 TTS (Piper/Kokoro)
Week 19-20 语音助手全链路 + VAD

交付： 离线语音助手 Demo

Phase 4 — 生态建设 (持续)

  • Model Hub 上线
  • 社区贡献指南
  • IoT 场景适配（与涂鸦设备打通）
  • 高级功能: LoRA 热加载、端侧微调、联邦学习

九、竞争优势分析

特性 本项目 llama.cpp MLC LLM MediaPipe
多模态 Pipeline 编排 ✅ ❌ ❌ 部分
移动端开箱即用 SDK ✅ ❌ ❌ ✅
LLM + Vision + Audio 统一 ✅ ❌ ❌ ❌
模型自动选择与降级 ✅ ❌ ❌ ❌
IoT 低端设备适配 ✅ ❌ ❌ ❌
流式 Pipeline ✅ 部分 部分 部分
Swift/Kotlin 原生 API ✅ 部分 ❌ ✅

核心差异点：不是又一个推理引擎，而是面向 APP 开发者的多模态 AI 能力层。

十、开源运营策略

License 选择

建议 Apache 2.0 — 商业友好，利于生态扩展。

社区建设

  1. 文档先行 — 完善的 Quick Start、API Reference、Architecture Guide
  2. Demo 驱动 — 每个 Feature 配套可运行的 Demo APP
  3. Benchmark 透明 — 公开各设备的性能数据，建立信任
  4. 贡献友好 — Good First Issue 标签、模型适配贡献指南
  5. 定期 Release — 双周迭代，月度正式版本
